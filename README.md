# oRIlo File Explorer

This version intentionally does **not** try to preview every file type.

- Images: thumbnails + open
- PDF/DOC/DOCX: file card + Open/Download
- RAR/ZIP/7Z: file card + Open/Download
- Video: file card only, no browser player
- Audio: file card only, no browser player
- Search, filters, grid/list views
- Data source: `kaderlaib19-alt/m3allKanfor`

## Install

Upload these files to:

`kaderlaib19-alt/kaderlaib19-alt.github.io`

Then enable GitHub Pages:

**Settings → Pages → Build and deployment → Source → GitHub Actions**

The site reads the public repository tree through the GitHub API.

## Important

This version does not copy the large files into the website repository. That avoids making GitHub Pages deployment fail because of large media files.

If GitHub API access is blocked by the visitor's network, the file list cannot be loaded from the browser.
